# StoryVenue UI 설계 문서

> 프론트엔드(역할 A, B)가 개발 전 참고할 화면 설계서입니다.

## 용어 통일

- 사용자에게 보여지는 단위는 **"이야기"** 로 통일합니다. (피그마 기준)
- 코드 식별자(`chapter_*`, `chapter_drafts` 등)는 백엔드와 일치하도록 유지하되, **UI 라벨은 모두 "이야기"** 로 표기합니다.
- 예: 챕터 초안 → 이야기 초안 / 챕터 생성 → 이야기 생성 / 챕터 1 → 이야기 1

---

## 1. 화면 흐름도 (Navigation Map)

```
[스플래시]
    |
    v
[로그인] <-------> [회원가입]
    |
    v
[홈] -----> [음성 인터뷰]
 |                  |
 |                  v
 |           [이야기 초안]
 |                  |
 |                  v
 |           [책 미리보기] ---> "피드에 올리기"
 |                                    |
 |--(하단탭: 피드)-->  [피드 목록] <---+
 |                        |
 |                        v
 |                  [피드 상세]
 |                        |
 |                        v  ("채팅하기" 버튼)
 |--(하단탭: 채팅)--> [채팅 목록]
 |                       |
 |                       v
 |                   [채팅방]
 |
 |--(하단탭: 프로필)--> [내 프로필]
 |
 |--(앱바: 알림 아이콘)--> [알림 목록]
```

### 화면 전환 정리

| 출발 | 도착 | 트리거 |
|------|------|--------|
| 스플래시 | 로그인 | 2초 후 자동 전환 (토큰 없을 때) |
| 스플래시 | 홈 | 2초 후 자동 전환 (토큰 있을 때) |
| 로그인 | 회원가입 | "회원가입으로 이동" 텍스트 탭 |
| 회원가입 | 로그인 | "이미 계정이 있어요" 텍스트 탭 |
| 로그인 | 홈 | 로그인 성공 |
| 홈 | 음성 인터뷰 | "새 인터뷰 시작" 버튼 |
| 음성 인터뷰 | 이야기 초안 | "이야기 생성하기" 버튼 |
| 이야기 초안 | 음성 인터뷰 | "다시 생성" 버튼 |
| 이야기 초안 | 책 미리보기 | "책에 추가" 버튼 |
| 책 미리보기 | 피드 목록 | "피드에 올리기" 버튼 |
| 피드 목록 | 피드 상세 | 게시물 카드 탭 |
| 피드 상세 | 채팅방 | "채팅하기" 버튼 |
| 피드 상세 | 피드 상세 (댓글 포커스) | 댓글 작성 후 목록에 반영 |
| 하단 탭 | 홈/피드/채팅/프로필 | 하단 네비게이션 바 탭 |
| 홈/피드/채팅 | 알림 목록 | 상단 앱바 알림 아이콘 탭 |
| 알림 목록 | 피드 상세 | 댓글 알림 항목 탭 |

|                                  |
|  +----------------------------+  |
|  | 인터뷰 #3  |  2026.03.28   |  |
|  | "어린 시절 이야기"           |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | 인터뷰 #2  |  2026.03.25   |  |

|  +----------------------------+  |
|  +----------------------------+  |

**상단 앱바:**
- 좌측: "안녕하세요, {이름}님"

- 알림 아이콘 탭 시 알림 목록 화면으로 이동
- ⚠️ 피그마 초기 디자인은 ⚙️ 설정 아이콘이지만, 설정 메뉴는 프로필 화면에 통합했으므로 🔔 알림으로 사용

**이전 인터뷰 카드 정보:**
- 인터뷰 번호
- 날짜
- 제목 (또는 첫 번째 이야기 제목)

### 2-7. 책 미리보기 화면 (역할 B)

```
+----------------------------------+
|  <  나의 이야기                   |
|                                  |
|  +----------------------------+  |
|  | 이야기 1: 어린 시절     [v] |  |
|  +----------------------------+  |
|  | 동네 골목에서 뛰어놀던      |  |
|  | 그 시절이 가장 행복했다...   |  |
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | 이야기 2: 첫 직장       [>] |  |
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | 이야기 3: 대학 시절     [>] |  |
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  |   이야기 더 만들기 (베이지)  |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  |   피드에 올리기 (머스타드)   |  |
|  +----------------------------+  |
|                                  |
+----------------------------------+
```

**아코디언 동작:**
- `[>]` 접힌 상태 — 제목만 표시
- `[v]` 펼친 상태 — 제목 + 본문 미리보기

**하단 버튼:**
- "이야기 더 만들기" → 음성 인터뷰 화면으로 이동 (이야기 추가)
- "피드에 올리기" → 안전 검사 후 피드 게시

### 2-9. 피드 상세 화면 (역할 B)

```
+----------------------------------+
|  <  김철수                        |
|                                  |
|  나의 첫 번째 이야기              |
|  (책 제목, 24sp, Bold)           |
|                                  |
|  +----------------------------+  |
|  |                            |  |
|  |  이야기 1: 어린 시절        |  |
|  |                            |  |
|  |  동네 골목에서 뛰어놀던     |  |
|  |  그 시절이 가장 행복했다.   |  |
|  |  여름이면 매미 소리가       |  |
|  |  온 동네를 가득 채웠고...   |  |
|  |                            |  |
|  |  (스크롤 가능, 전체 본문)    |  |
|  |                            |  |
|  +----------------------------+  |
|                                  |
|  ♡ 좋아요 12  |   💬 채팅하기    |
|                                  |
|  ── 댓글 3개 ──────────────────  |
|                                  |
|  +----------------------------+  |
|  | (O) 이영희    · 1시간 전    |  |
|  | 정말 감동적인 이야기네요!     |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | (O) 박지민    · 30분 전     |  |
|  | 다음 이야기도 기대됩니다     |  |
|  +----------------------------+  |
|                                  |
+----------------------------------+
| [댓글을 입력하세요...]     [전송] |
+----------------------------------+
```

**좋아요 버튼 상태:**
- 기본: 빈 하트 `♡` (회색)
- 누른 후: 채운 하트 `♥` (빨간색 #C0392B)

**댓글 영역:**
- 댓글 목록: 프로필 아바타 + 작성자 + 상대 시간 + 댓글 내용
- 하단 고정 입력창: 텍스트 필드 + 전송 버튼
- 전송 버튼: 입력 텍스트 있을 때만 활성 (진초록)
- 빈 상태: "첫 번째 댓글을 남겨보세요" 텍스트 표시

- 프로필 이미지: Large (80dp), 기본은 이름 첫 글자 아바타
- 이름: Heading3 (20sp, Bold)
- 이메일: Caption (14sp, 회색)

**메뉴 항목:**
- 내가 쓴 글: 내가 피드에 올린 게시물 목록으로 이동
- 좋아요한 글: 좋아요 누른 게시물 목록으로 이동
- 프로필 수정: 이름, 프로필 이미지 변경 화면으로 이동
- 로그아웃: 확인 다이얼로그 후 로그인 화면으로 이동

## 3. 공통 컴포넌트 목록

역할 A, B가 **함께 사용할** 공통 UI 요소입니다.  
한 명이 먼저 만들고 다른 사람이 재사용하세요.

### 3-1. 하단 네비게이션 바 (BottomNavBar)

```
+----------------------------------------------+
|  [홈]     [피드]     [채팅]     [프로필]       |
+----------------------------------------------+
```

- 사용 화면: 홈, 피드 목록, 채팅 목록, 내 프로필
- 선택된 탭: 진초록(#5F7A6A) 아이콘 + 텍스트
- 미선택 탭: 회색 아이콘 + 텍스트
- **담당**: 역할 A가 홈 화면에서 먼저 구현

### 3-2. 상단 앱바 (TopAppBar)

```
+----------------------------------+
|  [<]  제목                  [🔔] |
+----------------------------------+
```

- 사용 화면: 회원가입, 음성 인터뷰, 이야기 초안, 책 미리보기, 피드 상세, 채팅방
- `[<]` = 뒤로가기 버튼 (popBackStack)
- `[🔔]` = 알림 버튼 (알림 목록 화면으로 이동)
  - 표시 화면: 홈, 피드 목록, 채팅 목록, 내 프로필 (하단 탭이 있는 메인 화면들)
  - 읽지 않은 알림이 있을 때: 아이콘 우상단에 빨간 점 (badge)
  - 하위 화면 (회원가입, 채팅방 등)에서는 알림 아이콘 숨김
- **담당**: 역할 A가 먼저 구현

### 3-3. 기본 버튼 (PrimaryButton)

```
+----------------------------+
|        버튼 텍스트           |
+----------------------------+
```

- 진초록(#5F7A6A) 배경, 흰색 텍스트, 둥근 모서리 (8dp)
- 로딩 상태: 텍스트 대신 스피너 표시
- 비활성 상태: 옅은 베이지(#E2DED6) 배경
- **변형 1 (Accent)**: 머스타드(#D4A853) 배경 — "이야기 생성하기", "피드에 올리기" 등 강조 액션
- **변형 2 (Secondary)**: 베이지(#F0EDE6) 배경, 검은 텍스트 — "다시 생성", "이야기 더 만들기" 등

### 3-4. 텍스트 입력창 (StoryTextField)

```
+----------------------------+
| 라벨                        |
| [입력 내용]          [아이콘] |
+----------------------------+
  에러 메시지 (빨간색)
```

- 기본 배경: 베이지(#F0EDE6), 테두리 없음 (또는 옅은 베이지)
- 포커스: 진초록(#5F7A6A) 테두리
- 에러: 빨간색(#C0392B) 테두리 + 에러 메시지

### 3-5. 사용자 프로필 아바타 (ProfileAvatar)

```
  +----+
  | 김 |    ← 이름 첫 글자
  +----+
```

- 기본: 베이지(#F0EDE6) 원 + 이름 첫 글자 (진초록 텍스트)
- 크기: Small (32dp), Medium (40dp), Large (56dp/80dp)
- 사용 화면: 피드 카드, 채팅 목록, 채팅방, 내 프로필, 알림 목록

### 3-6. 카드 (StoryCard)

```
+----------------------------+
|  제목 (Bold)               |
|  설명 텍스트 (최대 2줄)     |
|  부가 정보 (회색, 작은 글씨) |
+----------------------------+
```

- 베이지(#F0EDE6) 배경, 둥근 모서리 (16~24dp), 옅은 그림자
- 사용 화면: 홈(인터뷰 목록), 피드(게시물), 채팅(목록)

## 5. 역할별 작업 순서 권장

### 역할 A (먼저 시작)
1. 공통 컴포넌트 (BottomNavBar, TopAppBar, PrimaryButton, StoryTextField)
2. 스플래시 → 로그인 → 회원가입
3. 홈 화면
4. 음성 인터뷰 화면

### 역할 B (역할 A의 STEP 1 이후 시작)
1. 역할 A가 만든 공통 컴포넌트 재사용
2. 이야기 초안 → 책 미리보기
3. 피드 목록 → 피드 상세
4. 채팅 목록 → 채팅방

> **역할 A가 공통 컴포넌트와 네비게이션 구조를 먼저 만들어야 역할 B가 수월하게 작업할 수 있습니다.**
