# 역할 A — Android UI 담당 (로그인 · 홈 · 음성 화면)

> **담당자**: \_\_\_\_\_\_\_\_  
> **브랜치 접두사**: `feature/ui-a/`  
> **핵심 기술**: Android Studio · Kotlin · Jetpack Compose

---

## 내 역할 한 줄 요약

앱을 켰을 때 사용자가 제일 먼저 보는 화면들을 만드는 역할입니다.  
로그인 화면, 홈 화면, 음성 인터뷰 화면의 **생김새와 버튼 동작**을 담당합니다.

---

## 내가 만들 화면 목록

| 화면 | 설명 |
|------|------|
| 스플래시 화면 | 앱 켰을 때 나오는 로딩 화면 |
| 로그인 화면 | 이메일/비밀번호 입력, 로그인 버튼 |
| 회원가입 화면 | 이름, 이메일, 비밀번호 입력 |
| 홈 화면 | 새 인터뷰 시작 버튼, 이전 인터뷰 목록 |
| 음성 인터뷰 화면 | 마이크 버튼, AI 응답 텍스트, 진행 상태 |

---

## 개발 환경 세팅 (처음 1회만)

### 1. Android Studio 설치
- 구글에서 "Android Studio 다운로드" 검색 후 설치
- 설치 중 나오는 옵션은 전부 기본값으로 OK

### 2. 새 프로젝트 클론
```bash
git clone <팀장에게 받은 GitHub 주소>
cd <프로젝트 폴더>/app
```

### 3. Android Studio로 열기
- Android Studio 실행 → `Open` → `app` 폴더 선택
- 우측 상단에 **Sync Now** 버튼 클릭 (패키지 자동 설치)
- 완료될 때까지 기다리기 (5~10분)

### 4. 에뮬레이터 세팅
- 상단 메뉴 → `Device Manager` → `Create device`
- `Pixel 6` 선택 → Android 14 선택 → `Finish`
- 재생 버튼 눌러서 에뮬레이터 켜기

## 단계별 할 일

### STEP 1 — 앱 기본 구조 만들기

**Codex에 붙여넣을 프롬프트:**
```
Android Kotlin Jetpack Compose 프로젝트를 새로 시작하려고 해.
MainActivity.kt 파일 하나에 아래 화면들을 NavHost로 연결해줘:
- splash (스플래시)
- login (로그인)
- signup (회원가입)
- home (홈)
- voice_interview (음성 인터뷰)
각 화면은 빈 Composable 함수로만 만들어줘. 네비게이션 구조만 완성해줘.
```

**완료 확인**: 에뮬레이터에서 앱이 실행되고 흰 화면이 뜨면 성공

**커밋:**
```bash
git commit -m "feat(auth): 앱 기본 네비게이션 구조 생성"
```

---

### STEP 2 — 로그인 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 로그인 화면을 만들어줘.
- 상단에 앱 이름 "StoryVenue" 텍스트 (크게)
- 이메일 입력창
- 비밀번호 입력창 (입력 내용 숨김 처리)
- "로그인" 버튼 (파란색)
- "회원가입으로 이동" 텍스트 버튼
버튼을 누르면 콘솔에 로그만 찍어줘. 아직 실제 연동은 안 해도 돼.
```

**완료 확인**: 에뮬레이터에서 로그인 화면이 보이면 성공

**커밋:**
```bash
git commit -m "ui(auth): 로그인 화면 레이아웃 구현"
```

---

### STEP 3 — 회원가입 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 회원가입 화면을 만들어줘.
- 이름 입력창
- 이메일 입력창
- 비밀번호 입력창
- 비밀번호 확인 입력창
- "회원가입" 버튼
- "이미 계정이 있어요" 텍스트 버튼 (누르면 로그인 화면으로 이동)
입력값 검증: 이메일에 @가 없으면 에러 메시지 표시
```

**커밋:**
```bash
git commit -m "ui(auth): 회원가입 화면 구현"
```

---

### STEP 4 — 홈 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 홈 화면을 만들어줘.
- 상단에 "안녕하세요, {이름}님" 텍스트
- 크고 눈에 띄는 "새 인터뷰 시작" 버튼 (가운데)
- 아래에 "이전 인터뷰" 제목과 빈 리스트 영역
- 하단 네비게이션 바: 홈, 피드, 채팅 아이콘
```

**커밋:**
```bash
git commit -m "ui(home): 홈 화면 레이아웃 구현"
```

---

### STEP 5 — 음성 인터뷰 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 음성 인터뷰 화면을 만들어줘.
- 상단: "인터뷰 중" 제목, 뒤로가기 버튼
- 가운데: AI가 한 말을 보여주는 텍스트 영역 (카드 형태)
- 하단 가운데: 크고 둥근 마이크 버튼
  - 기본 상태: 회색 마이크
  - 누르고 있을 때: 빨간색으로 변하고 "녹음 중..." 텍스트 표시
- 마이크 버튼 아래: "챕터 생성하기" 버튼
버튼 누르면 콘솔에 로그만 찍어줘.
```

**커밋:**
```bash
git commit -m "ui(voice): 음성 인터뷰 화면 레이아웃 구현"
```

---

### STEP 6 — 백엔드 팀과 연동하기

백엔드 팀(역할 C)이 API를 완성하면 같이 연동합니다.  
연동 전까지는 화면 디자인을 계속 다듬으세요.

**Codex에 붙여넣을 프롬프트:**
```
기존 로그인 화면에서 "로그인" 버튼을 누르면
POST http://10.0.2.2:8000/auth/login 에
{ "email": 입력한이메일, "password": 입력한비밀번호 }
를 보내고, 응답에서 access_token을 받아서 저장해줘.
실패하면 "로그인에 실패했습니다" 메시지를 화면에 보여줘.
```

**커밋:**
```bash
git commit -m "feat(auth): 로그인 API 연동 완료"
```
