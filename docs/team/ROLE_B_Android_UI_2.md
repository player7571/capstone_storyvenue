# 역할 B — Android UI 담당 (피드 · 채팅 · 책 화면)

> **담당자**: \_\_\_\_\_\_\_\_  
> **브랜치 접두사**: `feature/ui-b/`  
> **핵심 기술**: Android Studio · Kotlin · Jetpack Compose

---

## 내 역할 한 줄 요약

인터뷰가 끝난 뒤 사용자가 보게 되는 화면들을 만드는 역할입니다.  
책 미리보기, 피드(게시판), 채팅 화면의 **생김새와 버튼 동작**을 담당합니다.

---

## 내가 만들 화면 목록

| 화면 | 설명 |
|------|------|
| 챕터 초안 화면 | AI가 만든 챕터 텍스트를 보여주고 편집 가능 |
| 책 미리보기 화면 | 챕터들을 모아서 책처럼 보여줌 |
| 피드 화면 | 다른 사용자들의 게시물 목록 |
| 피드 상세 화면 | 게시물 하나를 자세히 보는 화면 |
| 채팅 화면 | 다른 사용자와 1:1 채팅 |

---

## 개발 환경 세팅 (처음 1회만)

### 1. Android Studio 설치
- 구글에서 "Android Studio 다운로드" 검색 후 설치
- 설치 중 나오는 옵션은 전부 기본값으로 OK

### 2. 새 프로젝트 클론
```bash
git clone <팀장에게 받은 GitHub 주소>
cd <프로젝트 폴더>/app
```

### 3. Android Studio로 열기
- Android Studio 실행 → `Open` → `app` 폴더 선택
- 우측 상단에 **Sync Now** 버튼 클릭
- 완료될 때까지 기다리기 (5~10분)

### 4. 에뮬레이터 세팅
- 상단 메뉴 → `Device Manager` → `Create device`
- `Pixel 6` 선택 → Android 14 선택 → `Finish`

> **역할 A와 같은 앱 프로젝트를 공유합니다.**  
> 작업 전에 항상 `git pull origin dev`로 최신 코드를 받아오세요.

## 단계별 할 일

### STEP 1 — 화면 라우트 추가

역할 A가 만든 네비게이션에 내 화면들을 추가합니다.

**Codex에 붙여넣을 프롬프트:**
```
기존 NavHost에 아래 화면 경로를 추가해줘:
- chapter_draft (챕터 초안)
- book_preview (책 미리보기)
- feed (피드 목록)
- feed_detail/{postId} (피드 상세, postId는 String)
- chat_list (채팅 목록)
- chat_room/{userId} (채팅방, userId는 String)
각 화면은 빈 Composable 함수로만 만들어줘.
하단 네비게이션 바는 홈, 피드, 채팅, 프로필 4탭으로 구성해줘.
```

**커밋:**
```bash
git commit -m "feat(book): 챕터/책/피드/채팅 화면 라우트 추가"
```

---

### STEP 2 — 챕터 초안 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 챕터 초안 화면을 만들어줘.
- 상단: "챕터 초안" 제목, 뒤로가기 버튼
- 챕터 제목 표시 텍스트 (굵은 글씨)
- 본문 내용을 보여주는 스크롤 가능한 텍스트 영역
- 하단 버튼 두 개:
  - "다시 생성" 버튼 (회색)
  - "책에 추가" 버튼 (파란색)
버튼 누르면 콘솔에 로그만 찍어줘.
```

**커밋:**
```bash
git commit -m "ui(chapter): 챕터 초안 화면 구현"
```

---

### STEP 3 — 책 미리보기 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 책 미리보기 화면을 만들어줘.
- 상단: 책 제목, 뒤로가기 버튼
- 챕터 목록을 카드 형태로 표시 (챕터 번호, 챕터 제목, 내용 미리보기)
- 카드를 누르면 챕터 상세 내용이 펼쳐지는 아코디언 방식
- 하단: "피드에 올리기" 버튼 (초록색)
더미 데이터로 챕터 3개를 미리 보여줘.
```

**커밋:**
```bash
git commit -m "ui(book): 책 미리보기 화면 구현"
```

### STEP 4 — 피드 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 피드(게시판) 화면을 만들어줘.
- 상단 앱바: 왼쪽에 "피드" 제목, 오른쪽에 알림 아이콘(🔔)
  - 알림 아이콘에 읽지 않은 알림이 있으면 빨간 점(badge) 표시
  - 알림 아이콘 누르면 알림 목록 화면으로 이동
- 게시물 카드 리스트 (LazyColumn 사용):
  - 프로필 사진 자리(회색 원), 작성자 이름, 작성 시간
  - 책 제목과 내용 미리보기 (2줄까지만)
  - 좋아요 하트 버튼, 좋아요 수, 댓글 수
- 카드를 누르면 피드 상세 화면으로 이동
더미 데이터로 게시물 5개를 보여줘.
```

**커밋:**
```bash
git commit -m "ui(feed): 피드 목록 화면 구현"
```

---

### STEP 5 — 피드 상세 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 피드 상세 화면을 만들어줘.
- 상단: 뒤로가기 버튼, 작성자 이름
- 책 제목 (크게)
- 본문 전체 내용 (스크롤 가능)
- 좋아요 버튼과 "채팅하기" 버튼 (좋아요 누르면 하트가 빨간색으로 변함)
- 댓글 영역:
  - "댓글 N개" 구분선
  - 댓글 리스트: 프로필 아바타 + 작성자 이름 + 상대 시간 + 댓글 내용
  - 댓글이 없을 때: "첫 번째 댓글을 남겨보세요" 텍스트
- 하단 고정: 댓글 입력창 + 전송 버튼
  - 전송 버튼은 텍스트가 있을 때만 활성화 (파란색)
더미 댓글 3개를 보여줘.
```

**커밋:**
```bash
git commit -m "ui(feed): 피드 상세 화면 구현"
```

---

### STEP 6 — 채팅 목록 화면 만들기

**Codex에 붙여넣을 프롬프트:**
```
Jetpack Compose로 채팅 목록 화면을 만들어줘.
- 상단 앱바: 왼쪽에 "채팅" 제목, 오른쪽에 알림 아이콘(🔔)
  - 알림 아이콘에 읽지 않은 알림이 있으면 빨간 점(badge) 표시
  - 알림 아이콘 누르면 알림 목록 화면으로 이동
- 채팅방 리스트 (LazyColumn):
  - 프로필 아바타 (회색 원, 이름 첫 글자)
  - 상대방 이름
  - 마지막 메시지 미리보기 (1줄, 말줄임)
  - 시간 (오른쪽 정렬)
- 채팅방을 누르면 채팅방 화면으로 이동
- 하단 네비게이션 바: 홈, 피드, 채팅, 프로필 (4탭, 채팅 선택 상태)
더미 데이터로 채팅방 3개를 보여줘.
```

**커밋:**
```bash
git commit -m "ui(chat): 채팅 목록 화면 구현"
```

**Codex에 붙여넣을 프롬프트:**

- 하단: 텍스트 입력창 + 전송 버튼

### STEP 8 — 백엔드 팀과 연동하기

백엔드 팀(역할 E)이 피드/채팅 API를 완성하면 연동합니다.

**Codex에 붙여넣을 프롬프트:**
```
피드 화면에서 앱이 로드될 때
GET http://10.0.2.2:8000/feed
를 호출해서 받아온 데이터로 게시물 목록을 보여줘.
로딩 중에는 스피너를, 실패하면 "데이터를 불러올 수 없습니다" 메시지를 보여줘.
```

**커밋:**
```bash
git commit -m "feat(feed): 피드 목록 API 연동 완료"
```
